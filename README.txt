Iulian Stancovici Portfolio Site V2

Open index.html in a browser.

Folder rules used by this build:
- 01_landscape = fullscreen landing-page background slideshow, 5 seconds per image.
- Numbered folders become category order only: 04_Scans displays as Scans.
- About folder/image is opened from the About button, not shown directly in the page flow.
- Contact links are at the end. Email is displayed as text, not a functional mail button.

For future uploads:
A static HTML site cannot automatically read newly added files from folders after deployment unless the file list is regenerated. Add images to the same folders, then rebuild/regenerate assets/data.js so the slideshow and galleries know the new filenames.
